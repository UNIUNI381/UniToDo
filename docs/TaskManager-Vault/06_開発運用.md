# 開発運用

## 環境

- Windows 10または11
- .NET 10 SDK。`global.json`は.NET 10.0.11のセキュリティ修正を含む`10.0.303`を最低版とし、同じ10系の最新Feature Bandへロールフォワード
- 全プロジェクトは`net10.0-windows`、警告をエラー扱い、lockファイルを使用
- ワークスペース内`.dotnet`を優先し、なければPATH上の.NET 10を使用
- ビルドと全テストはWindows PowerShell 5.1とPowerShell 7の両方に対応し、日本語を含むPowerShellスクリプトは5.1で誤解釈されない文字コードを維持する
- 頒布ZIP生成はPowerShell 7（`pwsh`）を使用する。Windows PowerShell 5.1には`System.IO.Path.GetRelativePath`がなく、allowlistコピー処理で停止する

## 標準コマンド

| 目的 | コマンド |
|---|---|
| ビルド | `./scripts/build.ps1` |
| 全テスト・静的検査 | `./scripts/test.ps1` |
| 自己完結発行 | `./scripts/publish.ps1` |
| 上書きインストール | `./scripts/install.ps1` |
| アンインストール | `./scripts/uninstall.ps1`。監視タスク、実行物、ショートカット、PATH登録を削除し、ユーザーデータは保持 |
| 個人データ検査済み頒布ZIP | `pwsh -NoProfile -File ./scripts/create-distribution.ps1`。詳細は[頒布と受取人セットアップ](08_頒布と受取人セットアップ.md) |
| TypeWhisper連携の確認・導入 | `./scripts/install-typewhisper-integration.ps1 -WhatIf`、同スクリプトの通常実行。詳細は[音声入力](07_音声入力.md) |
| 開発ツリーからCLI | `./scripts/task.ps1 <command>` |

配布物は`artifacts/publish/TaskManager`、インストール先は`%LOCALAPPDATA%\Programs\TaskManager`です。自己完結型`win-x64`なので利用時の別ランタイムを要求しません。発行時に`licenses/`を収録し、独自部分のMIT License、第三者一覧、発行に使用したWindows版.NET SDK付属文書、実行時NuGetパッケージ付属のLICENSE・NOTICE・Third-Party Notices全文をインストール後も確認できる状態にします。パッケージ付属文書は`licenses/packages/`へ配置し、`licenses/package-legal-files.json`で収録元とSHA-256を管理します。

直接頒布用ZIPは`artifacts/distribution`配下へ生成します。ワークスペース全体を直接圧縮せず、空のステージングへallowlist方式で必要ファイルだけを集めます。DB、資格情報、トークン、実タスク、作成者固有のCodexタスクIDを検出した場合に加え、発行済み`.deps.json`と`licenses/dependencies.json`が一致しない場合、パッケージ付属文書の索引と実ファイルのSHA-256が一致しない場合も頒布を失敗させます。詳細は[ライセンスと第三者コンポーネント](10_ライセンスと第三者コンポーネント.md)を参照します。

## 変更手順

1. `AGENTS.md`と[入口](00_入口.md)から関連ノートを確認する。
2. 既存の実データ・ユーザー変更を保護し、対象コードとテストを変更する。
3. スキーマ変更時は新しい版を追加し、適用直前のバックアップと旧DBからの移行テストを用意する。既存マイグレーションを書き換えない。
4. 画面変更時はHTML・JavaScript・CSSの整合と静的資産クエリ版を確認する。
5. 同じ作業でこのVaultの関連ノートを現在仕様へ更新する。
6. `scripts/test.ps1`を実行する。変更がインストール済みの本体やCLIへ影響する場合は、必要な発行・インストールと`127.0.0.1:48120`での起動確認まで行い、現環境へ反映する。第三者配布用ZIPはユーザーが頒布版の生成を明示した場合だけ作成・検査し、頒布対象ファイルや頒布スクリプトの変更だけでは生成しない。

## 実装規則

- 関数先頭、機能ブロック、数値計算へ日本語コメントを置く。
- 一文字や不要な略語を避け、意味の分かる変数名を使う。
- メンバー変数へ保持内容の短いコメントを付ける。
- UI、API、CLIで業務規則を重複実装せずServiceへ集約する。
- 同時更新はServiceの操作ロックとSQLiteトランザクションで整合させる。

## テスト観点

- 推薦：期限集中、厳守割込み、重要度、経過、継続性、予定余白、5,000件性能
- 依存：欠落、循環、開始可能日、親自動完了、中止時要確認
- 下書き：仮参照、冪等性、コミット前失敗、保存後警告
- プロジェクト：正規化、別名、あいまい候補、背景有効期間、既定期限、色
- 作業時間：単一タイマー、切替、警告、自動停止、重複、境界、10,000件集計
- Calendar：キャッシュ継続、安全な埋め込みURL
- ライセンス：lockファイルと依存一覧の一致、頒布時の発行依存一致、SDK付属文書と各実行時パッケージ付属文書の同梱・ハッシュ一致
- Codex音声入力：[音声入力](07_音声入力.md)のテスト観点を参照する。

## データ保護

- DB、バックアップ、資格情報、トークンをGitへ追加しない。追跡範囲とステージ検査は[ローカルGit管理](09_ローカルGit管理.md)に従う。
- SQLiteを手作業で修正しない。日常操作は`taskctl`、構造変更はマイグレーションを使う。
- 破壊的変更前にオンラインバックアップを作成する。
- OpenAI API、Apps Script、Google Sheets同期、外部公開用サーバーを追加しない。
- Calendar同期は`calendar.readonly`のまま維持する。

## 障害切り分け

| 症状 | 確認先 |
|---|---|
| 画面が古い | 静的資産クエリ版、配布物、インストール先、キャッシュ無効応答 |
| CLI接続失敗 | アプリ起動、`/api/v1/health`、固定ポート |
| DBロック | `busy_timeout`、長い接続、Service外の直接接続 |
| Calendar失敗 | credentials、DPAPIトークン、最終同期エラー、キャッシュ |
| 推薦が空 | 状態、開始可能日、依存、検証結果、現在空き時間 |
| タイマー不整合 | 単一実行索引、起動時整合処理、関連タスク状態 |
| アプリ停止 | Windowsタスク`LocalTaskManager Watchdog`の状態・最終結果、Windows復旧通知、ダッシュボードの未確認警告、`%LOCALAPPDATA%\TaskManager\logs`の`watchdog-*.log`・`watchdog-crash-*.log`・`crash-*.log`・`recovery-*.log`・`latest-system-incident.json`、監視親と本体の開始・終了、再起動結果 |
| 音声入力・Codex送信 | [音声入力](07_音声入力.md)の障害切り分け表 |
| `Not inside a trusted directory` | 常駐アプリがGit管理外の配置先から起動するため、Codex CLI引数に`--skip-git-repo-check`が含まれるか確認する。サンドボックス解除フラグで迂回しない |
