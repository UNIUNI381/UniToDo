# UniToDo 設計資料

このVaultは、AIまたは開発者が現在の実装を短時間で引き継ぐための索引です。変更履歴ではなく、常に現行仕様だけを記載します。

利用者向けの正式名称は`UniToDo`です。実行ファイル、プロジェクト、名前空間、保存先、APIヘッダーなどの開発上の識別子は互換性維持のため`TaskManager`のままです。

## 最初に確認すること

| 項目 | 現在値 |
|---|---|
| 対象 | Windows 10/11、単一ユーザー。Androidは任意のTailscale Serve経由 |
| 実行環境 | .NET 10 / `net10.0-windows` / `win-x64` |
| 画面・API | ASP.NET Core、待受は`http://127.0.0.1:48120`限定。Serveで本人のHTTPS接続を中継可能 |
| 正本データ | `%LOCALAPPDATA%\TaskManager\task-manager.db` |
| DBスキーマ | 版5 |
| AI操作 | `taskctl`経由。SQLite直接編集は禁止 |
| 外部連携 | Google Calendar読取専用、TypeWhisper、Ollama、Codex CLI |

## 正本の優先順位

1. ユーザーの現在の指示、[AGENTS.md](../../AGENTS.md)、適用するCodex Skill
2. ソースコード、DBマイグレーション、テスト
3. このVault
4. READMEなどの補助文書

実装とVaultが違う場合は、実装を確認してVaultを修正します。Vaultだけを根拠にDBや公開インターフェースを変更しません。

## 記録しない情報

- 実タスク、顧客、予定、作業ログなどの個人データ
- `credentials.json`、OAuthトークン、DB、バックアップの内容
- 一時的な調査ログや過去仕様
- ソースを見れば自明な全メソッド・全フィールドの転載
