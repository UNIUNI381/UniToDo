# ファイル構成

## ルート

```text
TaksManager/
├─ .agents/                 日常操作・システム更新用のリポジトリ内Codex Skill
├─ .gitignore               ローカルGitへ入れない生成物・個人データ
├─ src/TaskManager.App/     本体、API、業務処理、DB、画面、トレイ
├─ src/TaskManager.Cli/     taskctl実行ホスト
├─ integrations/            TypeWhisper出力プラグイン
├─ tests/TaskManager.Tests/ 独自コンソール型の受け入れ・性能テスト
├─ scripts/                 build/test/publish/installとCLIラッパー
├─ docs/                    AI操作ガイドとこのVault
├─ AGENTS.md                AI開発・タスク操作規則
├─ Install.ps1              頒布ZIPから本体とCodex Skillを導入
├─ 最初にお読みください.txt 受取人がCodexへ入力する最初のプロンプト
├─ README.md                導入と利用の概要
├─ Directory.Build.props    .NET共通設定
├─ global.json              .NET 10 SDK選択
└─ TaskManager.slnx         3プロジェクトのSolution
```

ローカルGitの追跡範囲と除外対象は[ローカルGit管理](09_ローカルGit管理.md)を参照します。

## `TaskManager.App`

| 場所 | 主な責務 |
|---|---|
| `Program.cs` | DI、ループバックWeb、静的配信、起動順、単一起動、異常終了ログ、自動再起動監視 |
| `Api/ApiEndpoints.cs` | `/api/v1`の全エンドポイントとHTTP変換 |
| `Api/LocalRequestMiddleware.cs` | ローカル要求以外の拒否 |
| `Domain/Models.cs` | タスク、設定、予定、推薦、下書き、プロジェクトモデル |
| `Domain/CodexModels.cs` | 音声確認要求とCodex送信モデル |
| `Domain/TimeTrackingModels.cs` | 作業ログと集計モデル |
| `Domain/SystemIncidentModels.cs` | 異常終了、復旧、通知、確認状態 |
| `Domain/TaskConstants.cs` | 状態、期限種別、変更元、固定URL |
| `Data/DatabaseInitializer.cs` | スキーマ版1～5、接続設定、バックアップ |
| `Data/TaskRepository.cs` | タスク、設定、予定、履歴、下書きの永続化 |
| `Data/ProjectRepository.cs` | プロジェクト、別名、背景、期限規則 |
| `Data/TimeEntryRepository.cs` | 作業ログ、重複、単一タイマー |
| `Services/TaskService.cs` | タスク状態遷移、下書き、タイマー連動 |
| `Services/RecommendationService.cs` | 候補評価、期限集中、推薦、カレンダー表示データ |
| `Services/ProjectService.cs` | 名前解決、背景統合、既定期限、色 |
| `Services/GoogleCalendarService.cs` | OAuthと読取専用同期 |
| `Services/AutomationWorker.cs` | 1分周期の通知、同期、バックアップ |
| `Services/TimeReportService.cs` | 日・週・月の作業時間集計 |
| `Services/SystemIncidentService.cs` | 異常終了情報のファイル保存、復旧通知、確認済み化 |
| `Services/Codex*` | タスクID正規化、確認・送信キュー、Codex CLI実行 |
| `Services/VoiceInputCoordinator.cs` | Ollamaの並行準備、TypeWhisper API・選択モデルの準備待ち、録音開始・停止状態の確認 |
| `Cli/CliRunner.cs` | taskctlの解析、API呼出し、JSON・終了コード |
| `Windows/ChildProcessJob.cs` | 監視親終了時に本体を孤児化させないWindows Job |
| `wwwroot/` | 単一ページUIのHTML、JavaScript、CSS、アイコン |
| `Assets/TaskManager.ico` | 実行ファイルとデスクトップショートカットで共有する緑のチェックアイコン |
| `Windows/TaskManagerTray.cs` | Webと同じ緑のチェックアイコン、トレイ、PC通知、F13受付、音声状態・確認画面の制御 |
| `Windows/CodexReviewForm.cs` | 校正済み本文の確認・編集・送信・破棄 |
| `Windows/TypeWhisperApiClient.cs` | TypeWhisperのディスカバリー情報、選択モデル、音声校正ワークフロー、録音状態をループバックAPIで扱う |
| `Windows/VoiceInputRuntime.cs` | Ollama・TypeWhisperの必要時起動と両APIの呼出し |
| `Windows/VoiceInput*` | 非アクティブ状態画面、F13登録、ローカルアプリ起動 |

音声入力関連ファイルの役割と外部配置先は[音声入力](07_音声入力.md)にまとめています。

## 変更箇所の探し方

| 要望 | 最初に確認する場所 |
|---|---|
| 画面表示・操作 | `wwwroot/index.html`、`app.js`、`styles.css` |
| API追加・HTTPエラー | `ApiEndpoints.cs`、対象Service |
| タスク状態・作業ログ連動 | `TaskService.cs`、Repository |
| 優先順位・空き時間 | `RecommendationService.cs`、`CalendarAvailabilityService.cs` |
| DB列・制約 | `DatabaseInitializer.cs`、モデル、Repository、移行テスト |
| taskctl | `CliRunner.cs`、`docs/AI_OPERATIONS.md`、`AGENTS.md` |
| 自動通知・同期 | `AutomationWorker.cs`、`GoogleCalendarService.cs` |
| プロジェクト解決 | `ProjectService.cs`、`ProjectRepository.cs` |
| 発行・インストール | `scripts/`、各`.csproj`、lockファイル |
| 頒布ZIP・受取人セットアップ | `scripts/create-distribution.ps1`、`Install.ps1`、`.agents/skills/`、[頒布設計](08_頒布と受取人セットアップ.md) |
| システム更新時のVault・Git整合 | `.agents/skills/update-task-manager-system/`、[入口](00_入口.md)、[ローカルGit管理](09_ローカルGit管理.md) |
| TypeWhisper・Codex音声送信 | `integrations/`、`Services/VoiceInputCoordinator.cs`、`Services/Codex*`、`Windows/VoiceInput*`、`Windows/CodexReviewForm.cs` |

新しい責務を追加した場合だけこの一覧を増やし、細かなメソッド名は記録しません。
